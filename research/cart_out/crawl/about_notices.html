Fonts that this package derives from JetBrains Mono (the identifier fonts the site serves) and
from Noto Sans, Noto Serif, Pangolin, and Mali (the subsets embedded in
generated PDFs) are Modified Versions
under the same license. They use a different font name. The identifier fonts carry no notice
inside the file: the license lets the notice be a stand-alone text file, and this file is that
notice. A product that serves those fonts includes this text in its third-party notices.

Atkinson Hyperlegible Mono is used unmodified: this package reads its outlines to draw
pictures of text and derives no font from it. The npm package's LICENSE file is the SIL Open
Font License 1.1 with no Reserved Font Name. The license description inside the font file
(name record 13) reads: "Braille Institute of America, Inc. provides Atkinson Hyperlegible
for use, without derivatives or alteration, to the public free of charge for all
non-commercial and commercial work. No attribution required." The two statements disagree
about modification, so no modified version of this typeface is made.
